# 🎮 Kid-Friendly Web Game Suite

A pair of colorful, highly accessible, browser-based games designed specifically for young children and school environments. Both games feature zero punishment, intuitive touch and keyboard controls, vibrant HTML5 Canvas vector graphics, and Web Audio API synthesized sound effects—all contained in lightweight, single-file applications.

---

## ⚽ Game 1: Super Sports Party! (4-in-1 Sports Suite)

**Super Sports Party!** is an energetic **4-in-1 sports game** built for toddlers and young kids aged **3–5 years old**. It encourages hand-eye coordination with forgiving hit detection and continuous positive visual reinforcement.

### 🕹️ Included Mini-Games

1. **⚽ Soccer Goal Striker**
   - **Gameplay**: Aim left or right and kick past the friendly Bear Goalie into the net!
   - **Goal**: Score exciting goals to unleash star explosions and whistle cheers.

2. **🏈 Football Touchdown Toss**
   - **Gameplay**: Time your pass across the football field to reach the running Fox Receiver.
   - **Goal**: Complete passes to score Touchdowns!

3. **🏀 Basketball Tap Tap Shots**
   - **Gameplay**: Arcade *Tap Tap Shots* floating physics! Tapping or pressing action propels the basketball up and forward towards a moving hoop.
   - **Goal**: Score swishes, perform bank shots off the backboard, and build up streak multipliers to set the ball on fire! 🔥

4. **⚾ Baseball Home Run Hitter**
   - **Gameplay**: Single-tap timing swing! A friendly pitcher throws a slow, easy-to-see baseball to home plate.
   - **Goal**: Blast Home Runs out of the park for fireworks and cheering celebrations!

### 🌟 Key Features
- **Toddler-Friendly Design**: Zero fail states or game-over screens. Missing a shot simply resets the ball safely with encouraging sound effects.
- **Synthesized Audio Engine**: All whistles, kicks, swishes, bat hits, and crowd cheers are synthesized dynamically in real-time.
- **Dual Controls**: Giant, easy-to-tap buttons for small fingers on mobile/tablet screens, plus full keyboard binding (`Spacebar`, `Enter`, `Arrow Keys`).

## 🎀 Game 2: Darling Doll Studio ✨ (School Edition)

**Darling Doll Studio ✨** is a kawaii chibi avatar creator inspired by classical dress-up games, specifically tailored to be **100% school-appropriate and kid-friendly**.

### 🌟 Key Features

1. **🏫 School-Appropriate Modesty Guarantee**
   - The doll features a permanent pastel camisole & bike shorts modesty base layer.
   - Even when removing all optional dresses, tops, or skirts, the doll remains fully and respectfully dressed for school environments.

2. **👧 Unified Face & Body Customization**
   - **Skin Tone Engine**: Synchronized across the head, ears, neck, face, arms, and legs.
   - **Facial Expressions**: Customizable anime eyes, winks, mouth expressions, blush tones, and cheek band-aids/stickers.

3. **💇‍♀️ Modular Layered Hair System**
   - Separate front bangs and back hairstyles (twin pigtails, long waves, crown braids, cute bobs, afro puffs).
   - Instant color swatch bar allowing kids to turn hair golden, cotton candy pink, mint green, or chocolate brown.

4. **👗 Comprehensive Wardrobe & Accessories**
   - **Outfits**: Sailor school uniforms, magical girl gowns, denim overalls, popstar glitz dresses, and fairy gowns.
   - **Tops & Skirts**: Mix-and-match hoodies, tees, pleated skirts, and tutus.
   - **Shoes & Props**: High tops, ballet flats, boba milk tea, plushies, heart glasses, cat/bunny ears, and cute pets (calico kitten, puppy, baby panda, dragon).

5. **📸 Interactive Features**
   - **5 Scene Backgrounds**: Kawaii Classroom, Cherry Blossom Park, Cozy Bedroom, Crystal Castle, and Starry Night.
   - **💬 Speech Bubbles**: Customizable speech bubbles ("Kawaii!", "School Day!", "Best Friends!").
   - **🎲 "Surprise Me!" Button**: Generates instant randomized fashion combinations.
   - **📷 Photo Studio**: Takes a snapshot of the styled doll for kids to save to their device.

## 🕹️ Controls Reference Guide

### ⚽ Super Sports Party! Controls
| Action | Keyboard | Touch Screen / Mouse |
| :--- | :--- | :--- |
| **Main Action** *(Kick / Toss / Shoot / Swing)* | `Spacebar`, `Enter`, `Up Arrow` | Tap Giant Action Button or tap directly on Game Canvas |
| **Aim Left / Right** | `Left Arrow` / `Right Arrow` | Tap Big ⬅️ / ➡️ Navigation Arrows |
| **Sound Toggle / Menu** | Header Buttons | Tap Header HUD Icons |

### 🎀 Darling Doll Studio ✨ Controls
| Action | Keyboard | Touch Screen / Mouse |
| :--- | :--- | :--- |
| **Equip Items / Change Colors** | — | Tap category buttons, color swatches, or item cards |
| **Tap Sparkles** | — | Tap or click directly anywhere on the doll canvas |
| **Surprise Outfit** | `Spacebar` or `R` key | Tap **🎲 Surprise Me!** Button |
| **Switch Categories** | `Left` / `Right` Arrow Keys | Tap Category Header Tabs |

## 💻 Technical Setup & Compatibility

- **Technology**: Single-file HTML5, CSS3 (Tailwind CSS CDN), Vanilla JavaScript Canvas API, and Web Audio API.
- **Zero Dependencies**: 100% self-contained code requiring no external image or audio file assets.
- **How to Play**: Open `index.html` in any modern desktop or mobile web browser (Chrome, Safari, Firefox, Edge).
